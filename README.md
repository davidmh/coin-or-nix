COIN-OR Nix flake
-----------------

Convenience Nix flake with a more recent version of [cbc] from the COIN-OR project.

Nixpkgs already has a formula for [cbc], but it's too old.

[cbc] depends on [clp], [cgl] and [osi], which are also built in this flake.

[cbc]: https://github.com/coin-or/Cbc
[cgl]: https://github.com/coin-or/Cgl
[clp]: https://github.com/coin-or/Clp
[osi]: https://github.com/coin-or/Osi
